## 5. Design System (v1.0)

The Egostix Media identity is built on restraint, precision, and structural grid alignment. The brand speaks through system execution, not decoration.

### Color System

#### Primary Palette

- **Blue 700 (#1d4ed8):** Primary Accent. The sole primary accent color — used strictly for CTAs, links, active states, and highlights.
- **Blue 600 (#366110):** Hover / Active state representation.
- **Blue 900 (#1e3aba):** Dark Accent.
- **Blue 100 (#dbeafe):** Tinted Background / Badges / Info callouts. Use sparingly.
- **Slate 900 (#0f172a):** Primary Text color.
- **White (#ffffff):** Surface / Background. All pages are light-first and start from solid white.

#### Neutrals

- **Slate 900** (`#0f172a`)
- **Slate 700** (`#334155`)
- **Slate 500** (`#64748b`)
- **Slate 300** (`#cbd5e1`)
- **Slate 100** (`#f1f5f9`)
- **Off-White** (`#fafafa`)

#### Semantic Colors

- **Error / Danger:** `#ef4444`
- **Warning:** `#f59e0b`
- **Success:** `#22c55e`
- **Info / Link:** `#1d4ed8`

#### Color Rules

- White is the default surface. Never use dark backgrounds by default.
- Maintain WCAG AA contrast (4.5:1). **Never** place Slate 500 text on a White background for body copy.
- **Never** place light text on Blue Pale (`#dbeafe`) backgrounds.

### Typography

- **Primary Typeface:** **Geist** (Variable sans-serif by Vercel).
- **Fallback Typeface:** Inter, system-ui, sans-serif.
- **Weights Used:** 400 Regular, 500 Medium, 600 Semibold, 700 Bold.
- **Rules:** Do not use decorative or display fonts. Never use more than 2 typefaces in a single composition.

| **Display** | 48px | 52px        | Bold     | Hero headings        |

### Spacing Scale (Base-8)

All UI layouts must adhere to an 8px grid alignment system.

| Token      | Pixels | REM     | Visual Role                  |
| ---------- | ------ | ------- | ---------------------------- |
| `space-1`  | 4px    | 0.25rem | Micro-icon padding           |
| `space-2`  | 8px    | 0.5rem  | Tight-inline gaps            |
| `space-3`  | 12px   | 0.75rem | Compact small components     |
| `space-4`  | 16px   | 1rem    | Base unit — standard padding |
| `space-5`  | 20px   | 1.25rem | Comfortable — cards          |
| `space-6`  | 24px   | 1.5rem  | Relaxed — section gaps       |
| `space-8`  | 32px   | 2rem    | Loose between sections       |
| `space-10` | 40px   | 2.5rem  | Airy — major sections        |
| `space-12` | 48px   | 3rem    | Spacious hero padding        |
| `space-16` | 64px   | 4rem    | Layout page margins          |

### Grid System

- **Desktop (1440px+):** 12 columns | 24px gutter | 80px margin | Max content width: 1280px
- **Tablet (768px - 1439px):** 8 columns | 16px gutter | 40px margin | Max content width: 720px
- **Mobile (<768px):** 4 columns | 16px gutter | 20px margin | Max content width: 100%

### UI Component Patterns

- **Buttons:** Standardized variants: Primary (Main CTA - max one per view), Secondary (Supporting actions), Ghost (Outlined low emphasis), Danger (Destructive actions), and Soft (Subtle tinted CTA).
- **Cards:** Fixed patterns for contextual display:
  - *Service Card:* Systems, Not Campaigns. Focuses on frameworks that scale and evolve. Includes "Learn more →".
  - *Outcome Card:* Outcomes Over Output. Clear representation of real changes, avoiding fluff. Includes "Learn more".
  - *Insight Card:* Intelligence Compounds. Emphasizes learning loops and system growth. Includes "Learn more →".

### Motion & Animation Principles

- **Purposeful:** Every animation must carry meaning (state change, hierarchy, or feedback). Never decorative.
- **Restrained:** Less is more. Use motion sparingly so when it appears, it commands attention.
- **Instant-Feeling:** Animation must feel instant at scale. Never block user intent with slow transitions.

#### Duration & Easing

- **Instant (0ms):** Focus rings, active ticks.
- **Fast (100ms):** Tooltips, micro-interactions.
- **Standard (200ms):** Dropdowns, mobile nav toggles.
- **Slow (300ms):** Modals, side panels.
- **Deliberate (500ms):** Page transitions.
- **Curves:**
  - `ease-out` (`cubic-bezier(0, 0, 0.2, 1)`): Elements entering or arriving on screen.
  - `ease-in` (`cubic-bezier(0.4, 0, 1, 1)`): Elements exiting or leaving the screen.
  - `ease-in-out` (`cubic-bezier(0.4, 0, 0.2, 1)`): Same element morphing / state change.
  - `linear` (`cubic-bezier(0, 0, 1, 1)`): Loaders, continuous or progress motion.

## 6. Brand Voice & Copywriting Patterns

### Tone Attributes

- **Precise:** No filler, no fluff. Every word earns its place on the page.
- **Confident:** Stated without bravado or hedging. We know what we are doing.
- **Systems-Minded:** Think in loops, not one-offs. Language reflects architectural principles.
- **Intelligent:** Write for smart people. Assume competence, not confusion.

### Headline Formula

When creating titles and headlines for the website, use the following pattern:
$$\text{\[What we do]} + \text{\[For whom]} + \text{\[What changes as a result]}$$
*Example:* "We deliver results as a service — creativity, engineering, and intelligence merged into one seamless system."

### Copywriting Do's & Don'ts

| DO (Write this)                        | DON'T (Avoid this)                                     |
| -------------------------------------- | ------------------------------------------------------ |
| "We build systems that survive scale." | "Our solutions are synergistic and scalable!"          |
| "Results, not deliverables."           | "We're passionate about delivering value!"             |
| "Intelligence compounds with use."     | "AI-powered cutting-edge innovation."                  |
| "Contact us to begin."                 | "Reach out and let's connect and chat!"                |
| "Depth beats volume."                  | "Comprehensive end-to-end solutions for all."          |
| Lead copy with outcomes, not features. | Write vague superlatives like "best" or "world-class". |

## 7. Strict Implementation Guidelines

- **Theme & Palette Constraints:** Do **not** add a second accent color alongside Blue (`#1d4ed8`). Keep layouts light-first (white surfaces). Do not use gradients or drop shadows on the logo mark.
- **Component Composition:** Maintain an exact 8px grid spacing scale alignment. Do not mix component border radii inconsistently across a screen views. Let whitespace breathe.
- **Process Sequence Consistency:** Always present or link workflows following the exact 4-step execution phrasing: **Discover → Prototype → Integrate → Scale**. Never stretch, compress, or alter logo proportions.
